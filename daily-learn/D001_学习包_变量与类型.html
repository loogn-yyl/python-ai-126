3变量与类型：和 C 的差别在哪

① 变量不用声明类型

# C:  int age = 18;
age = 18
name = "小明"
height = 1.75
is_student = True
nothing = None

Python 里变量就是个"标签"，贴在值上。值有类型，变量没有类型——同一个变量你可以先放数字再放字符串，Python 不会拦你（但别这么写）。

② C 与 Python 对照表

概念C 写法Python 写法
整数int a = 10;a = 10
小数float b = 3.14;b = 3.14
字符char c = 'A';没有 char，c = 'A' 是字符串
字符串char s[] = "hi";s = "hi"
布尔int flag = 1;flag = True（首字母大写）
空值NULLNone（首字母大写）
输出printf("%d", a);print(a)
语句结尾必须有 ;不需要分号
代码块{ }靠缩进（4 个空格）

③ 用 type() 看类型

a = 10
b = 3.14
c = "hello"
d = True
e = None

print(type(a))
print(type(b))
print(type(c))
print(type(d))
print(type(e))
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
容易搞错的两点：
1. True / False / None 首字母必须大写，写成 true 会报 NameError。
2. Python 没有 char，单引号包起来的也是一个字符的字符串，可以 'A' + 'B' 得到 'AB'；C 里这是两个数字相加。

4运算符：那个最容易踩的除法坑

运算符含义例子结果

/真除法，结果永远是 float7 / 23.5
//整除，向下取整7 // 23

⚠️ C 程序员第一大坑：C 里 7 / 2 等于 3，Python 里等于 3.5。
要整除必须写 7 // 2。这个差异会让你在"算分钟数""分页"这类场景里算错，务必记住。

5字符串与 f-string 格式化

这是你以后用得最多的东西。单引号双引号等价，三引号可以写多行。

s = "Hello Python"
print(s.upper())        # 全大写
print(s.lower())        # 全小写
print(len(s))           # 长度
print(s[0])             # 第一个字符 H
print(s[-1])            # 最后一个字符 n
print(s[0:5])           # 切片，前 5 个 Hello
print(s.split(" "))     # 按空格切分成列表
print(s.replace("Hello", "Hi"))

f-string：Python 里最好的字符串拼接

在字符串前面加个 f，花括号里可以直接放变量或表达式：

name = "小明"
age = 18
score = 87.5678

print(f"我叫{name}，今年{age}岁")
print(f"明年我{age + 1}岁")
print(f"成绩保留一位小数：{score:.1f}")
print(f"成绩保留两位小数：{score:.2f}")
print(f"百分比：{score:.1f}%")
我叫小明，今年18岁
明年我19岁
成绩保留一位小数：87.6
成绩保留两位小数：87.57
百分比：87.6%
:.2f 是什么：冒号后面是格式说明，.2 表示两位小数，f 表示浮点数。这相当于 C 的 printf("%.2f")，但不用操心类型匹配。

6input()：从键盘拿数据

input() 会暂停程序等你输入，按回车才继续。

name = input("请输入你的名字：")
print(f"你好，{name}")
⚠️ C 程序员第二大坑：input() 永远返回字符串！
哪怕你输入的是 18，拿到的也是 "18"（字符串）。
要当数字用，必须转换：age = int(input("年龄：")) 或 float(input(...))。
不转的话，"18" + 1 会报 TypeError。

正确写法：

age = int(input("请输入年龄："))
height = float(input("请输入身高（米）："))
print(f"你 {age} 岁，身高 {height} 米")

print() 还有两个有用参数：

print("a", "b", "c")              # 默认用空格隔开
print("a", "b", "c", sep="-")     # 用 - 隔开
print("第一行", end="")            # end 改结尾符，默认是换行
print("第二行")
a b c
a-b-c
第一行第二行

7动手写 3 个脚本（今天的核心产出）

脚本 1：温度转换 temp.py

新建文件：nano temp.py，把下面代码粘进去，Control+O 回车保存，Control+X 退出。

# temp.py  摄氏度转华氏度
c = float(input("请输入摄氏度："))
f = c * 9 / 5 + 32
print(f"{c} 摄氏度 = {f:.1f} 华氏度")

运行：python temp.py

请输入摄氏度：37
37.0 摄氏度 = 98.6 华氏度

加难度（自己写）：让它支持反向转换——输入华氏度也能算摄氏度，公式是 (f - 32) * 5 / 9。

脚本 2：BMI 计算 bmi.py

这个脚本要引入 if 判断，是今天唯一的新语法：

# bmi.py  计算 BMI 并给出区间
height = float(input("请输入身高（米，如 1.75）："))
weight = float(input("请输入体重（公斤）："))

bmi = weight / (height ** 2)
print(f"你的 BMI 是 {bmi:.2f}")

if bmi < 18.5:
    print("偏瘦")
elif bmi < 24:
    print("正常")
elif bmi < 28:
    print("偏胖")
else:
    print("肥胖")
请输入身高（米，如 1.75）：1.75
请输入体重（公斤）：70
你的 BMI 是 22.86
正常
注意语法：if 条件后面有冒号，下一行要缩进 4 个空格，没有花括号。缩进错了 Python 会直接报 IndentationError。
