🚀 Python AI 应用开发 · 18 周学习规划

依据「王道 Python AI 应用开发方向课程大纲」定制 · 结合你已有的 C 语言基础

⏱ 每天 4 小时（每周 28 小时）
📅 总时长约 18 周
🎯 目标：具备 AI 应用开发就业能力

🧭 学情分析与总体策略

  • 你的优势：有 C 语言基础，已理解变量、循环、函数、指针内存等底层概念，Python 语法阶段可以明显提速（比零基础快约 40%），把省下的时间投入项目实战。
  • 你的短板：Python 生态（面向对象、装饰器、异步）、Linux/Docker 工程环境、AI 应用框架（LangChain、RAG）都是从零开始，这些是本规划的重点。
  • 时间分配：每天 4 小时建议拆为——2 小时看课/读文档 + 1.5 小时动手写代码 + 0.5 小时整理笔记。务必"看一节、写一节"，绝不只看不动手。
  • 总节奏：前 7 周打基础（阶段 1–3），第 8–15 周主攻 AI 应用开发核心（阶段 4–5），第 16–18 周算法补充与冲刺就业（阶段 6–8）。

📅 每日时间安排模板

第 1 小时：学习新知识看课程视频 / 读官方文档，理解当天的核心概念
第 2–3 小时：动手编码跟着敲代码 + 独立完成练习，报错自己先查
第 4 小时：复盘与笔记整理知识点到笔记，周末用半天做本周小结项目

💡 周日可以灵活调整：半天复习本周内容 + 半天休息，避免疲劳积累。

🗺 分阶段详细规划

1

Python 基础语法

第 1 – 2.5 周（约 70 小时）
周次内容目标
第 1 周Python 语法快速过一遍：变量、数据类型、流程控制、函数、异常；对比 C 与 Python 差异（动态类型、引用语义、缩进）能独立写 100 行以内的小程序
第 2 周面向对象（类、继承、魔法方法）＋ 文件操作 ＋ 函数式部分（lambda、map/filter）能用类封装一个小型学生管理系统
第 2.5 周高级语法：迭代器、生成器、闭包、装饰器；正则表达式；网络编程（socket 对比你在 C 里的经验）理解装饰器原理，能手写一个计时装饰器
✅ C 基础加速点：语法本身熟悉得快，把更多精力放在「Pythonic 写法」和面向对象思维上——这是和 C 差异最大的部分。
2

基础服务与工程环境

第 3 – 5 周（约 84 小时）
周次内容目标
第 3 周Linux 常用命令、Shell 基础、Git 版本管理（从第一天起所有代码都提交到 GitHub/Gitee）熟练在 Linux 终端下工作，Git 工作流成型
第 4 周（上）SQL：MySQL 建表、CRUD、Join、索引基础能设计并操作一个业务数据库
第 4 周（下）–5 周（上）Redis 数据类型与缓存场景；Docker 镜像/容器/docker-compose能用 Docker 一键启动 MySQL + Redis 环境
第 5 周（下）FastAPI + Uvicorn：路由、Pydantic 校验、异步接口；用 Vibe Coding（Claude Code / Codex）完成一个阶段项目并上线独立开发并部署一个 RESTful API 小项目（如待办事项服务）
⚠️ 这是很多人容易轻视的阶段，但它是后面所有项目部署的底座，Docker 和 Git 一定要练熟。
3

数据处理与 AI 基础

第 6 – 7 周（约 56 小时）
周次内容目标
第 6 周Jupyter Notebook 使用；NumPy 数组运算、广播；Pandas 的 DataFrame、数据清洗与分组统计能独立完成一份真实 CSV 数据的清洗分析报告
第 7 周Coze / Dify 低代码平台入门，动手搭建一个问答机器人并发布上线拥有第一个可展示的 AI 应用作品
🎯 里程碑 1（第 7 周末）：完成 3 个可展示作品——CLI 小工具、FastAPI 部署项目、Coze/Dify 问答机器人，全部有 Git 提交记录。
4

RAG 系统全栈开发 ⭐ 核心重点

第 8 – 10 周（约 84 小时）
周次内容目标
第 8 周大模型 API 调用（Prompt 工程基础）；LangChain 核心：Model I/O、Chain、Memory能调用 LLM API 构建多轮对话应用
第 9 周Embedding 与向量数据库（FAISS/Milvus）；文档切分、检索；Function Calling 与 MCP 协议、Skill 机制手写一个最小可用 RAG 流程
第 10 周LangGraph 编排、Agent 原理；RAG 优化（重排序、混合检索）、Graph RAG；实战 RAG 项目开发并上线上线一个完整的知识库问答系统（简历级项目）
⭐ RAG 是当前 AI 应用开发岗位考察频率最高的技能，这部分学完要能讲清「文档 → 切分 → 向量化 → 检索 → 生成」全链路的每个环节和常见优化手段。
5

AI Agent 项目实战 ⭐ 核心重点

第 11 – 13 周（约 84 小时）
周次内容目标
第 11 周Rasa 框架、DIET 多任务学习架构；意图识别、实体抽取、特征工程优化搭建一个基于 Rasa 的对话机器人
第 12 周统一网关、多智能体编排与调度（Multi-Agent 协作模式）理解主流 Multi-Agent 架构并画出设计图
第 13 周医疗行业智能体项目实战上线 或 金融/电商行业多智能体项目实战上线（二选一做深，另一个了解思路）完成第二个简历级项目，含架构设计与部署
🎯 里程碑 2（第 13 周末）：拥有 2 个上线项目（RAG 知识库 + 行业智能体），整理项目文档与架构说明，简历初稿成型。
6

开源智能体实战

第 14 周（约 28 小时）
周次内容目标
第 14 周研究 OpenClaw、Hermes、Harness 等开源智能体项目：读源码结构、跑通 Demo、尝试二次开发一个小功能并提交 PR 或写源码分析文章能读懂一个开源 Agent 项目的架构
7

大模型算法与原理

第 15 – 17 周（约 84 小时）
周次内容目标
第 15 周机器学习基础（scikit-learn）：线性回归、逻辑回归、决策树、评估指标理解经典 ML 流程与常用指标
第 16 周深度学习与 PyTorch：张量、自动求导、训练循环；Transformer 架构精读（Attention 机制）、BERT手写简易 Attention；能讲清 Transformer 结构
第 17 周HuggingFace 生态；迁移学习与微调：LoRA / PEFT 微调实战完成一次开源小模型的 LoRA 微调并记录过程
💡 应用开发岗对算法要求是「够用 + 能讲原理」：重点吃透 Transformer 和微调实操，传统 ML 掌握概念即可，不必陷入数学推导太久。
8

面试就业冲刺

第 18 周起（持续进行）
内容要点
简历优化用 STAR 法则包装 2 个上线项目，突出 RAG、Agent、微调关键词与量化成果
真实场景模拟面试每周至少 2 次模拟面试（可用 AI 辅助面试工具），覆盖八股 + 项目深挖 + 手撕代码
高频面试题整理 Python 高频题、RAG/Agent 场景题、Transformer 原理题，形成自己的题库
往期进友经验分享关注往期学员面经，针对性查漏补缺；持续投递 + 复盘
🎯 里程碑 3：简历定稿 → 开始投递 → 每次面试后 24 小时内复盘更新题库。

✅ 贯穿全程的 4 条纪律

  • 代码即作品：从第 1 天起所有代码进 Git，项目全部传 GitHub，这是面试时的硬通货。
  • 项目优先：时间不够时砍视频、不砍动手；每个阶段末尾的项目必须完整跑通。
  • 善用 AI 工具：Claude Code / Codex 既是大纲里的课程内容，也是你日常的学习加速器——用它解释报错、审查代码，但核心逻辑必须自己写。
  • 每周复盘：周日花 30 分钟检查：本周计划完成率、卡点是什么、下周如何调整。连续两周完不成就下调任务量，保住节奏比堆量更重要。

注：阶段时长参考王道官方大纲并结合 C 语言基础做了加速调整，实际执行中可根据上表灵活微调。
