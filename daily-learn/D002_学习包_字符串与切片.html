1字符串是什么：不可变序列

Python 的字符串是一个字符序列，同时支持两件事：像 C 的数组一样按下标访问，像对象一样调用方法。

s = "Hello Python"

print(len(s))        # 长度
print(s[0])          # 第一个
print(s[-1])         # 最后一个
print(s[6])          # 第 7 个（下标从 0 开始）
12
H
n
P

关键特性：不可变

s = "hello"
s[0] = "H"        # 想改第一个字符
TypeError: 'str' object does not support item assignment
⚠️ 和 C 最大的区别：C 里 char s[] = "hello"; s[0] = 'H'; 完全合法，Python 里直接报错。
Python 的字符串一旦创建就不能修改任何字符，所有"修改"操作（`replace`、`upper`、`strip`）都是返回一个新字符串，原字符串不变。这是新手最容易误解的地方。 
s = "hello"
t = s.upper()

print(s)    # 原字符串没变
print(t)    # 新字符串
hello
HELLO

和 C 字符串的完整对比

对比项CPython
底层char 数组，以 \0 结尾对象，内部记录长度与编码
求长度strlen() 遍历到 \0，O(n)len(s) 直接读长度，O(1)
可否修改可以，s[0]='H'不可以，所有方法返回新串
拼接strcat()+ 或 join()
单引号内容'A' 是 char（1 字节）'A' 是 str（长度 1）
中文需要 wchar_t 或 UTF-8 字节数组原生支持，len("中文") = 2

2切片：Python 最强的基础能力

语法是 s[start:stop:step]，三个参数都可省略。取到 stop 之前为止，不包含 stop。

带步长

s = "0123456789"

print(s[::2])     # 每隔 2 个取一个（偶数位）
print(s[1::2])    # 从 1 开始，每隔 2 个
print(s[::-1])    # 步长为 -1 → 反转
print(s[8:2:-2])  # 从 8 倒着走到 2 之后，每次跨 2

记住这一个：s[::-1] 是反转字符串。面试高频题"判断回文"就靠它：s == s[::-1]。

切片不会报错（这点和索引不同）

s = "abc"
print(s[10])      # 索引越界 → 报错
print(s[10:20])   # 切片越界 → 返回空字符串
Traceback ... IndexError: string index out of range
（第二行正常输出空行）
实用意义：切片是"安全"的，哪怕范围离谱也不崩；索引是"危险"的，越界直接抛异常。所以处理用户输入时，能用切片就别用索引。

4f-string 进阶：格式控制

D001 学过的 :.2f 只是开始。f-string 的完整格式是 {值:填充对齐 宽度 .精度 类型}。

常用格式符

写法含义示例结果
:.2f两位小数f"{3.14159:.2f}"3.14
:g智能格式（去掉多余的 .0）f"{37.0:g}"37
:d整数f"{42:d}"42
:08.2f宽度 8、补 0、两位小数f"{3.14:08.2f}"00003.14
:03d宽度 3、补 0f"{7:03d}"007
:,千分位分隔f"{1234567:,}"1,234,567
:.1%百分比f"{0.256:.1%}"25.6%
:>10右对齐，宽 10f"{'hi':>10}" hi
:<10左对齐f"{'hi':<10}"hi
:^10居中f"{'hi':^10}" hi

对齐的实际用途：打印表格

rows = [("苹果", 3, 12.5), ("香蕉", 10, 4.0), ("西瓜", 1, 30.0)]

print(f"{'商品':<6}{'数量':>4}{'单价':>8}")
print("-" * 18)
for name, qty, price in rows:
    print(f"{name:<6}{qty:>4}{price:>8.1f}")
商品    数量    单价
------------------
苹果     3   12.5
香蕉    10    4.0
西瓜     1   30.0
⚠️ 发现了吗：数字没有和"数量""单价"对齐。这不是你写错了，是中文比英文宽造成的。

宽度参数 {:<6} 里的 6 数的是字符个数，屏幕上占多少格子它不管。一个汉字算 1 个字符，但显示时占 2 格（等于两个英文字母宽）。

算一下就明白了：
· 表头 {'数量':>4} → 2 个汉字已占满 4 个字符位，不再补空格 → 屏幕实际宽度 2 + 4 = 6 格
· 数据 {3:>4} → 补 3 个空格 + 1 个数字 → 屏幕宽度 4 格
两者差 2 格，所以后面的列整体左移了。

解法一：含中文的表格，宽度按"显示宽度"算

写两个小工具函数（中文算 2 格，英文算 1 格），以后所有中文表格都能用：

import unicodedata

def dw(s):
    """显示宽度：中文/全角算 2，英文算 1"""
    return sum(2 if unicodedata.east_asian_width(c) in "WF" else 1 for c in s)

def ljust_cn(s, width):
    return s + " " * max(0, width - dw(s))

def rjust_cn(s, width):
    return " " * max(0, width - dw(s)) + s


rows = [("苹果", 3, 12.5), ("香蕉", 10, 4.0), ("西瓜", 1, 30.0)]

print(ljust_cn("商品", 8) + rjust_cn("数量", 6) + rjust_cn("单价", 8))
print("-" * 22)
for name, qty, price in rows:
    print(ljust_cn(name, 8) + rjust_cn(str(qty), 6) + rjust_cn(f"{price:.1f}", 8))
商品      数量    单价
----------------------
苹果         3    12.5
香蕉        10     4.0
西瓜         1    30.0

解法二：偷懒但够用

中文表头不参与宽度控制，手动补空格；或者干脆用英文表头：

print(f"{'name':<8}{'qty':>5}{'price':>8}")
for name, qty, price in rows:
    print(f"{name:<8}{qty:>5}{price:>8.1f}")
什么时候需要在意：自己调试时随便对齐就行；但后面做数据报表、CLI 工具输出，或者给业务方看的终端表格，中文对齐就必须处理——面试里"怎么打印对齐的中文表格"也是常见问题。
注意这一行："-" * 18 —— 字符串可以直接乘数字，得到重复内容。C 里得写循环，Python 一行搞定。同理 "ab" * 3 得到 "ababab"。

f-string 里可以放任何表达式

x = 7
name = "小明"

print(f"{x * 2 + 1}")               # 算术
print(f"{name.upper()}")            # 方法调用
print(f"{'成年' if x >= 18 else '未成年'}")   # 条件表达式
print(f"{len(name)} 个字")           # 函数调用
15
小明
未成年
2 个字
⚠️ 一个 {} 里只能放表达式，不能再套 {}。昨天
f"{max{max(a,b), c}}" 报 SyntaxError 就是这个原因。正确写法是 f"{max(a, b, c)}"——函数用圆括号。

什么时候该加 f，什么时候不用

判断标准只有一条：这段字符串里有没有变量要"嵌进去"。有就用 f，没有就不用。

场景写法要不要 f
输出固定文字print("程序开始")❌ 不要
打印变量本身print(name)❌ 不要（直接传变量）
打印表达式结果print(a + b)❌ 不要
文字里夹变量print(f"你好，{name}")✅ 要
要控制格式（小数位/对齐/补零）print(f"{score:.1f}")✅ 必须用
调试看数据结构print(data)❌ 不要（f 反而看不清类型）
name = "小明"
score = 87.5678

print("程序开始")                  # 固定文字，不用 f
print()                            # 空行，不用 f
print(name)                        # 打变量本身，不用 f
print(f"你好，{name}")              # 文字夹变量，用 f
print(f"得分：{score:.1f}")          # 要格式，必须用 f
两种典型的错法：
① 该加没加 —— print("你好，{name}") 输出的是字面量 你好，{name}，花括号原样打印，不报错但结果错。
② 不该加却加了 —— print(f"程序开始") 不会出错，只是多余，读代码的人会以为这里本该有变量。

另一种写法：print 的多个参数

name = "小明"
age = 18

print("姓名：", name, "年龄：", age)     # 逗号分隔，自动插空格
print(f"姓名：{name} 年龄：{age}")        # f-string，完全可控
姓名： 小明 年龄： 18
姓名：小明 年龄：18
区别：逗号分隔会自动插入空格（所以"姓名："后面多了个空格），格式不受控；f-string 想在哪放什么就在哪放。正式输出一律用 f-string，临时调试可以用逗号。

5编码：中文为什么占 3 个字节

这个知识点今天看着抽象，但后面处理 CSV、读文件、调 API 时，80% 的乱码问题都源于它。

s = "中文abc"

print(len(s))                       # 字符数
print(len(s.encode("utf-8")))       # UTF-8 下的字节数
print(s.encode("utf-8"))            # 实际的字节
5
9
b'\xe4\xb8\xad\xe6\x96\x87abc'

怎么算的：一个中文字符在 UTF-8 下占 3 个字节，两个中文 = 6 字节，三个英文字母 = 3 字节，合计 9。

编码英文中文说明
ASCII1 字节不支持最早的编码，只有 128 个字符
GBK1 字节2 字节中文 Windows 的默认编码
UTF-81 字节3 字节现在的事实标准，Mac/Linux 默认
# 编码：字符串 → 字节
b = "你好".encode("utf-8")

# 解码：字节 → 字符串
s = b.decode("utf-8")

print(b)
print(s)
b'\xe4\xbd\xa0\xe5\xa5\xbd'
你好
⚠️ 常见报错预演：用错的编码解码 
"你好".encode("gbk").decode("utf-8")
会抛 UnicodeDecodeError。这就是"乱码"的本质——用 A 编码存的，用 B 编码读。
记住三条就够用了：
1. 读文件、写文件、连数据库，统一用 UTF-8
2. len() 数的是字符，不是字节
3. 遇到乱码，先查"存的时候用的什么编码"，而不是急着改代码
