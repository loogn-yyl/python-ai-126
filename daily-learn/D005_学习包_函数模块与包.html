2默认参数，以及那个著名的坑

def greet(name, greeting="你好"):
    return f"{greeting}，{name}"

print(greet("张三"))
print(greet("张三", "早上好"))
print(greet(greeting="晚上好", name="李四"))
你好，张三
早上好，张三
晚上好，李四
最后一行是「关键字参数」：按名字传，顺序随便。C 没有这个能力。
规则：带默认值的参数必须放在不带默认值的后面。def f(a=1, b) 会直接 SyntaxError。

坑来了：默认参数里写可变对象

下面这段代码看起来很合理，但结果会让所有人愣一下。请务必亲手跑一遍。

def bad(item, box=[]):
    box.append(item)
    return box

print(bad(1))
print(bad(2))
print(bad(3))
[1]
[1, 2]
[1, 2, 3]
⚠️ 你要的应该是 [1]、[2]、[3]，为什么列表一直在累积？

因为 默认值只在函数「定义」时创建一次，不是每次调用都新建。box=[] 里的那个列表是函数对象的一部分，所有调用共用同一个。

用 D003 的知识理解：box 这个名字始终指向同一个列表对象（就是「赋值是指针」那个道理），append 一直在改它。

正确写法：默认值用 None，函数内部再建

def good(item, box=None):
    if box is None:
        box = []          # 每次调用都新建一个
    box.append(item)
    return box

print(good(1))
print(good(2))
[1]
[2]
记成一条铁律：默认参数永远不要写 []、{}、set() 这些可变对象，一律写 None 然后在函数里判断。
字符串、数字、元组、True/False 这些不可变的可以放心当默认值。

这是 Python 面试最高频的坑之一，也是实际项目里最难查的 bug 之一——因为它不报错，只是「数据莫名其妙多了」。

3*args 和 **kwargs：参数数量不定

def total(*args):
    return sum(args)

print(total(1, 2, 3))
print(total(1, 2, 3, 4, 5))
6
15
def profile(**kwargs):
    for k, v in kwargs.items():
        print(f"{k}: {v}")

profile(name="张三", age=18)
name: 张三
age: 18
写法收到什么怎么用
*args一个元组，装所有多余的位置参数sum(args)、for x in args
**kwargs一个字典，装所有多余的关键字参数kwargs["name"]、kwargs.items()
⚠️ 名字不重要，星号才重要。*args 和 *nums 完全等价，args / kwargs 只是约定俗称的名字。但星号数量决定了收的是元组还是字典：
· 一个星号 → 多余的位置参数，装成元组
· 两个星号 → 多余的关键字参数，装成字典

反过来用：把列表拆成参数

nums = [3, 1, 4, 1, 5]

print(max(nums))       # 传一个列表进去
print(max(*nums))      # 拆成 5 个参数，效果一样但意义不同
5
5
什么时候需要 *nums：当函数不接受列表、只接受一个个参数的时候。比如 print(*nums) 会输出 3 1 4 1 5（空格分隔），而 print(nums) 输出的是 [3, 1, 4, 1, 5]。这个技巧以后打印结果时很常用。

4多返回值：靠元组

Python 函数只能 return 一个值，但「一个值」可以是元组——所以看起来像返回了多个。

def minmax(nums):
    return min(nums), max(nums)      # 实际返回一个元组

lo, hi = minmax([3, 1, 4, 1, 5])
print(lo, hi)

print(minmax([3, 1, 4]))            # 直接打印能看到是个元组
1 5
(1, 4)
这就是 D003 元组解包最实用的场景。lo, hi = minmax(...) 一次拆两个。C 里要返回多个值得传指针进去改，Python 直接返回元组就行。

5作用域：LEGB 四层查找

x = "全局"

def outer():
    x = "外层"
    def inner():
        x = "内层"
        print(x)      # 先找自己这层
    inner()
    print(x)          # 再找 outer 这层

outer()
print(x)
内层
外层
全局
L · Local函数内部
E · Enclosing外层函数
G · Global模块全局
B · Built-in内置（print、len 等）
规则：Python 找一个变量名时，按 L → E → G → B 的顺序就近找，找到就停。
所以三个 x 各在各的层，互不干扰，输出三个不同的值。

函数里改全局变量：要声明 global

count = 0

def add():
    global count      # 声明「我要改的是外面那个」
    count += 1

add()
add()
print(count)
2
⚠️ 不加 global 会报 UnboundLocalError，而不是「改不了但也不报错」。
因为只要函数体里出现了 count = ...（包括 +=），Python 就认定 count 是这个函数的局部变量，那么 count += 1 就等于「读一个还没赋值的局部变量」→ 报错。
但更好的做法是：别用 global。
全局变量让函数变得「有状态」，两个函数互相影响，调试起来很痛苦。正确做法是把状态当参数传进去、返回值带出来： 
def add(count):
    return count + 1

count = 0
count = add(count)
count = add(count)
print(count)
效果一样，但函数是「纯」的——给同样的输入永远得同样的输出。这是后面写所有项目、所有 AI 应用的基本要求（D007 的通讯录项目就是这么设计的：数据当参数传，不靠 global）。

6lambda：一行写完的小函数

double = lambda x: x * 2
print(double(5))

# 完全等价于
def double2(x):
    return x * 2
print(double2(5))
10
10
⚠️ lambda 只适合「一行能写完的表达式」。不能写 if 语句块、不能写 for 循环、不能有多条语句。需要这些就用 def。
不要给 lambda 起名字——double = lambda x: x*2 这种写法其实不如直接 def double(x): return x*2，可读性更好。lambda 的真正用武之地是当参数传。

真正的用途：给 sorted 传排序规则

nums = [3, 1, 4, 1, 5]
print(sorted(nums, key=lambda x: -x))       # 按相反数排 = 降序

students = [("张三", 88), ("李四", 95), ("王五", 76)]
print(sorted(students, key=lambda s: s[1]))
[5, 4, 3, 1, 1]
[('王五', 76), ('张三', 88), ('李四', 95)]
key=lambda s: s[1] 怎么读：「对每个元素 s，取它的第 2 项（分数）来比较」。
也可以用 reverse=True 代替 -x 的取负技巧，两种都行，看场景。

map 和 filter：lambda 的另一半搭档

nums = [3, 1, 4, 1, 5]

print(list(map(lambda x: x * 2, nums)))     # 每个都乘 2
print(list(filter(lambda x: x > 2, nums)))   # 只要大于 2 的
[6, 2, 8, 2, 10]
[3, 4, 5]
但这两个用推导式写更清楚： 
nums = [3, 1, 4, 1, 5]
print([x * 2 for x in nums])
print([x for x in nums if x > 2])
map/filter 配 lambda 是「函数式」写法，推导式是「Pythonic」写法。都认识，但日常优先用推导式——一眼能看出「在干嘛」，而且不用套 list()。

7模块与包：把代码拆成多个文件

今天的重点。函数解决了「代码重复」，模块解决「文件太长」。

先理解 import 在干什么

import math                 # 整个模块拿进来，用 math.xxx 访问
print(math.sqrt(16))
print(math.pi)

from math import sqrt, pi   # 只拿需要的名字，直接用
print(sqrt(16))
print(pi)

import math as m            # 起个别名（常用：import numpy as np）
print(m.sqrt(16))

4.0
写法之后怎么用什么时候用
import mathmath.sqrt()推荐默认，来源清晰
from math import sqrtsqrt()用得很多、名字不冲突时
import math as mm.sqrt()名字太长，如 import numpy as np
from math import *直接全用不要用，不知道名字从哪来
⚠️ C 的 #include 是把文件内容直接贴进来，Python 的 import 完全不是。
import 是执行那个文件一次，然后拿到它里面的变量和函数。所以：
· import 同一个模块两次，文件只执行一次（有缓存）
· 被 import 的文件里如果有 print()，import 的时候就会打印
第二点就是下面 if __name__ == "__main__" 存在的理由。

# utils.py
"""常用小工具函数"""

def area_circle(r):
    """圆面积"""
    return 3.14159 * r * r

def celsius_to_fahrenheit(c):
    """摄氏转华氏"""
    return c * 9 / 5 + 32

def is_leap(year):
    """判断闰年"""
    return (year % 4 == 0 and year % 100 != 0) or year % 400 == 0

def minmax(nums):
    """同时返回最小值和最大值"""
    return min(nums), max(nums)


# 只有直接运行 utils.py 时才执行，被 import 时不执行
if __name__ == "__main__":

    print(is_leap(2024))

if __name__ == "__main__" 到底是什么

这是 Python 新手最懵的一行。拆开看就三件事：

问题答案
__name__ 是什么每个文件都有个内置变量 __name__
它的值是多少直接运行这个文件 → "__main__"
被别的文件 import → 文件名（如 "utils"）
所以这行在干嘛「只有在直接运行我时才执行下面这块」——相当于 C 的 main()
# 验证一下：把这段存成 whoami.py，然后分别用两种方式跑
print("__name__ 的值是:", __name__)

# 方式一：python whoami.py          → __main__
# 方式二：在别的文件里 import whoami → whoami
为什么必须要写这一行：
不加的话，main.py 一 import utils，utils 里的测试代码就全跑了，屏幕上冒出一堆不该有的输出。
加上的话：自己跑 = 带自测；被别人 import = 只提供函数，安静不出声。

以后你写的每个模块都该这么收尾，这是 Python 的通用惯例。

# utils.py
"""D005 练习：我自己的工具模块"""

import math


def area(r):
    """圆面积"""
    return math.pi * r * r


def greet(name, greeting="你好"):
    """生成问候语"""
    return f"{greeting}，{name}"


def average(*nums):
    """求平均值，没有参数时返回 0"""
    if not nums:
        return 0
    return sum(nums) / len(nums)


def describe(**info):
    """打印所有配置项"""
    for k, v in info.items():
        print(f"{k}: {v}")


def stats(nums):
    """返回 (最小值, 最大值, 平均值)"""
    return min(nums), max(nums), sum(nums) / len(nums)


if __name__ == "__main__":
    print("--- utils 自测 ---")
    print(f"{area(2):.2f}")
    print(greet("张三"))
    print(average(1, 2, 3))
    describe(name="李四", age=20)
    print(stats([3, 1, 4, 1, 5]))
# main.py
import utils


print(f"圆面积: {utils.area(2):.2f}")
print(utils.greet("张三"))
print(f"平均值: {utils.average(1, 2, 3)}")
print(f"空参数: {utils.average()}")
utils.describe(name="李四", age=20)
print(utils.stats([3, 1, 4, 1, 5]))

# D005 笔记

## 函数基础
- def name(param): 缩进，没有 {} 和类型声明
- 没有 return 的函数返回 None（不是「不返回」）
- print 是给人看，return 是给程序用
- 函数内部尽量只 return 不 print，输出交给调用方

## 参数
- 默认参数必须放在后面
- **默认参数不能写 [] {} set()** —— 只会创建一次，所有调用共用
  正确写法：默认 None，函数里 if x is None: x = []
- *args 收成元组，**kwargs 收成字典
- 反向用：max(*nums) 把列表拆成参数

## 作用域 LEGB
- Local → Enclosing → Global → Built-in，就近找
- 改全局变量要 global，但更好的做法是当参数传、用返回值带出

## lambda
- 一行表达式，不能有多语句
- 主要用途：sorted(key=...)、map、filter 的参数
- 但 map/filter 用推导式更清楚

## 模块
- import math / from math import sqrt / import numpy as np
- 不要写 from xxx import *
- import 会执行那个文件一次（所以要有 __main__ 保护）
- __name__：直接运行 = "__main__"，被 import = 文件名
- 包 = 带 __init__.py 的文件夹，点号就是路径

## C 对比
- #include 贴内容，import 执行模块并拿名字
- void 函数 vs 返回 None
- 返回多个值：C 要传指针，Python 返回元组
