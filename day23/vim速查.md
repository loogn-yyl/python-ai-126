# vim 速查（只记我用了还会忘的）

## 保命三条
- 迷路了：Esc Esc
- 存盘退出：:wq
- 不存盘退出：:q!

## 进插入模式
i 光标前插 / a 后插 / o 新开下一行

## 我实际用到的
| 动作 | 键 |
| --- | --- |
| 跳末尾 | G |
| 跳第 N 行 | NG |
| 行首/行尾 | 0 / $ |
| 删一个字 | x |
| 删一行 | dd |
| 撤销 | u |
| 复制 N 行| Nyy |
| 粘贴 | p |
| 全局替换 | :%s/旧/新/g |
| 搜索 | /关键词 然后 n 下一个 N 上一个 |

## 还没练熟的
- 可视模式选块: v 进入然后移动 —— d 删 —— y 复制 —— > 整块缩进
- 分屏
- 显示行号: `:set nu`
- 打开另一个文件: `:e 路径`
