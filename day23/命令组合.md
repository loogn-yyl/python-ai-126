# D023 五组命令组合

## 1. 找占空间最多的东西
- 当前目录下每个子目录多大，倒序取前 5
```
du -sh ~/python-learn/* 2>/dev/null | sort -h | tail -n 5
```

我的实际输出：
```
92K	/Users/loogn/python-learn/day20
136K	/Users/loogn/python-learn/portfolio
192K	/Users/loogn/python-learn/day14
452K	/Users/loogn/python-learn/Icon 
1.1M	/Users/loogn/python-learn/daily-learn
```  

- 找出大于 50MB 的单个文件
```
find ~ -type f -size +50M 2>/dev/null -exec ls -lh {} \; | sort -k5 -h | tail -n 10
```
排序必须用 -h（认 K/M/G 后缀），不能用 -n：ls -lh 打印的 5.8M 交给 sort -n 会被当成数字 5，于是 5.8M 排到 900K 前面。

## 2. 从日志定位问题
```
log=~/linux-lab/logs/access.log
```

### ① 状态码分布
```
awk '{print $5}' $log | sort | uniq -c | sort -rn
```
我的实际输出：
```
   3 200
   1 500
   1 401
```

### ② 只看 5xx，带行号
```
grep -n " 5[0-9][0-9] " $log
```
我的实际输出：
```
5:2026-11-20 10:02:30 GET /api/users 500 64
```

### ③ 出错最多的 URL 前 3
```
awk '$5>=400 {print $4}' $log | sort | uniq -c | sort -rn | head -n 3
```
我的实际输出：
```
   1 /api/users
   1 /api/login 
```

### ④ 把错的行单独存一份，同时看有多少条
```
grep " 5[0-9][0-9] " $log | tee ~/linux-lab/logs/err.log | wc -l
```
我的实际输出：
```
       1
```
字段号记牢：这份日志是六字段（日期 时间 方法 路径 状态 大小），**状态码在 $5**。nginx 默认 combined 格式才是 `$9`。

## 3. 打包备份排除垃圾
```
cd ~/python-learn
tar -czf ~/backup-python-learn-$(date +%Y%m%d).tar.gz \
    --exclude="__pycache__" \
    --exclude=".git" \
    --exclude="*.pyc" \
    .

ls -lh ~/backup-python-learn-*.tar.gz
```

我的实际输出：  
```
-rw-r--r--  1 loogn  staff   5.8M 11月 26 15:59 /Users/loogn/backup-python-learn-20261126.tar.gz
```

## 4. 批量改名 / 批量加权限
```
cd ~/linux-lab
mkdir -p rename-demo && cd rename-demo
touch a.txt b.txt c.txt
``` 

- 把 .txt 全改成 .md（先 echo 演练，确认无误再执行）
```
for f in *.txt; do echo "mv \"$f\" \"${f%.txt}.md\""; done
```

- 确认后去掉 echo 真正执行
```
for f in *.txt; do mv "$f" "${f%.txt}.md"; done
ls
```

我的实际输出：
```
mv "a.txt" "a.md"
mv "b.txt" "b.md"
mv "c.txt" "c.md"
a.md	b.md	c.md  
```

## 5. 传到远程 / 从远程取回
- 传一个文件上去
```
scp ~/backup-python-learn-20261126.tar.gz local:~/
```

我的实际输出：
```
backup-python-learn-20261126.tar.gz                                                   100% 5931KB 370.4MB/s   00:00
```

- 传整个目录（-r）
```
ssh local "mkdir -p ~/backup"
scp -r ~/python-learn/day22 local:~/backup/
```

我的实际输出：
```
命令实操记录.md                                                                       100% 5457    10.2MB/s   00:00
```

- 从服务器拉一个文件下来
```
scp local:~/linux-lab/logs/access.log /tmp/remote-access.log
awk '$5>=400' /tmp/remote-access.log | wc -l
```

我的实际输出：
```
access.log                                                                            100%  218   572.3KB/s   00:00    
       2
```

- 更推荐：rsync（断点续传、只传改动部分、能排除）
```
rsync -avz --exclude="__pycache__" ~/python-learn/day22 local:~/backup/
```

我的实际输出：
``` 
Transfer starting: 2 files
day22/
day22/?\#221?令?\#236?\#223\#215记?\#225.md

sent 3199 bytes  received 48 bytes  1546190 bytes/sec
total size is 5457  speedup is 1.68
```
那串 `?\#221` 是 rsync 2.6.9（macOS 自带的老版本）把 UTF-8 文件名的每个字节转义打印的结果，实际文件名是 day22/命令实操记录.md。换成 Homebrew 装的新版 rsync 就正常显示。
