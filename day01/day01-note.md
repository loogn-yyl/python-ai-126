# D001 笔记

## 今天学会的
- 变量不需要声明类型，值有类型
- True/False/None 首字母大写
- / 返回float， // 才返回整除int
- f"{变量:.2f}"控制小数点后几位，{变量:g}智能格式
- input()返回字符串，返回整数必须int(input())

## Python 与 C 的差异
- Python不需要分号
- Python没有char，单个字符也是str
- 代码块不需要{}
- import math 包含 math.pi

## 终端操作
- nano新建/打开文件
- Control + O然后enter保存
- Control + X退出
- ls当前目录下文件
- cat 文件名.类型 查看文件内容
- tab键自动补全
- cd 目录名
