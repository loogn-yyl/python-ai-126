## 三、管道组合
1. `awk '{print $1}' f | sort | uniq -c | sort -rn | head`  ← 频次排行
2. `cat f | head` 是多余写法, 但读起来顺，写长管道时不容易漏
3. `cut -d' ' -f4 logs/access.log | sort | uniq -c | sort -rn` → 取文件第4列，并出现次数排行
4. `find . -name "*.py" -exec wc -l {} \;` —— `-exec ... {} \;` 是 find 的「对每个结果执行一条命令」，{} 是占位符，\; 是结束标记（分号必须转义，否则被 shell 吃掉） —— 多用 + 代替 \;
5. `find . -name "*.py" | xargs wc -l` —— xargs 是整批处理, -exec \; 是逐个处理  
   注意: 文件名带空格时 xargs 会切错, 当成两个参数 —— 两头加 -0: `find . -print0 | xargs -0 rm`

## 四、实战配方 
-  配方 1：这个项目里提到 TODO 的 Python 文件，按修改时间排  
`grep -rn --include="*.py" "TODO" . | cut -d: -f1 | sort -u | xargs ls -lt 2>/dev/null | head -n 5`

- 配方 2：当前目录下大于 50MB 的文件，按大小排（没有输出 = 没有这么大的文件）  
`find . -type f -size +50M -exec ls -l {} + | sort -k5 -n | tail -n 5`

- 配方 3：日志里出现最多的前 5 个 URL  
`awk '{print $4}' ~/linux-lab/logs/access.log | sort | uniq -c | sort -rn | head -n 5`

## 五、BSD 与 GNU 差异（我实际踩到的）
- 原地改文件: sed -i 要写 sed -i ''
- 按日期算时间戳: `date -d "2026-11-22" +%s` 要写 `date -j -f "%Y-%m-%d" "2026-11-22" +%s`
- 时间戳转日期: `date -d @1700000000` 要写 `date -r 1700000000`
- 看文件大小: `stat -c "%s %n" f` 要写 `stat -f "%z %N" f`
- grep 用 PCRE: `grep -P "\d+"` 对应BSD没有类似命令，要用 grep -E 或 brew install grep 后用 ggrep -P
- find 打印属性: `find . -printf "%s\n"`对应BSD没有 -printf，用 -exec stat
- 看 tab 字符: `cat -A f` 要写 `cat -et f`
- 服务管理: `systemctl restart nginx` 要写 `brew services restart nginx`
- 装软件: `apt install x` 要写 `brew install x`
- 看内存: `free -h` 要用 `vm_stat / 活动监视器`
